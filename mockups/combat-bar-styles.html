Combat bar — style mockups

Five styles for the combat target's hp bar. Each row shows the same five target states (100% / 75% / 50% / 25% / 5%) so you can see how the bar drains as the opponent loses health. All variants share a bright-red → dim-red color ramp. Pick one (or mix two) and I will wire it in.

1. track drain smooth CSS bar, single color drains from bright red at full hp to a dark muddy red as the opponent dies. simplest, matches the current combat track-bar shape.
2. shade glyphs, drain uses the same ▓░ glyphs as the vitals "spark" bar's top row. filled cells take the drain color (brighter → darker), empty cells stay a near-black red so the trough is always visible.
3. per-cell shade ramp every filled cell carries its own shade — leftmost cells stay bright red, rightmost cells fade through the ramp. as cells fall off the right, only the brightest stay lit. reads as "how much damage left to do" at a glance.
4. pulse on low track bar that pulses below 30% (slow) and faster + glowing below 10%. signals "kill imminent" without taking extra screen real estate.
5. spark combat mirrors the vitals spark style — drain-colored ▓░ bar on top, two- sample-per-cell braille history below tracking the target's hp over recent ticks. shows both "where the opponent is now" and "how fast they are dropping".

Combat chip — layout variants

Same bar (style #2 — shade drain) shown in four chip shapes. Combat at 55% target hp with a "small wounds" condition.

A. current (3-row stack) today's shape — name on row one, bar + pct on row two, condition on row three. tallest of the four; takes ~3 lines of vertical space.
B. one-line (matches mockups above) swords + name + bar + pct on a single row. condition tucked into the name line as a parenthetical. tightest vertical footprint; long target names truncate with ellipsis.
C. two-row, bar-leads bar on row one (full chip width), name + pct + condition on row two. the bar reads first — quickest "how dead is it" glance. name drops to a supporting role.
D. minimal (no pct, color = hp) drops the percent readout entirely; bar color (bright→dim) IS the hp indicator. condition stays for narrative. cleanest, but loses the precise number.

Selected: one-line + percent inside (inverse)

Percentage sits inside the bar; the text uses mix-blend-mode: difference with white so it auto-inverts against whatever color is behind it — bright red fill on the left becomes teal/cyan, the dark trough on the right becomes near-white. Always readable, no manual color switching.
