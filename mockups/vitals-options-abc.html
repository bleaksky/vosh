a single line of colored event glyphs. each cell encodes the most recent event: ▾ red = hp loss, ▴ red = hp heal, ▾ cyan = mn spend, ▾ amber = mv spend, ─ dim = idle tick. strip scrolls left; the rightmost cell is "now" and pulses briefly when an event lands. less about "how much" and more about "what just happened" — busy strip = chaotic turn, calm strip = nothing fired.

shared simulation: all three demos read from the same event stream, so a single combat tick fires all three to update simultaneously. swap scenarios and watch the cadence differ. integration footprint: the vitals slot in each shell is the same vertical band where vosh's current vitals bar lives — between scrollback and the input row. nothing here would change the rest of the chrome.
