vitals · panel-sized braille graph

one graph, three vitals overlaid. each vital owns its own colored layer (hp red · mn cyan · mv amber); overlapping columns blend so a moment where hp and mn dropped together reads as magenta. each column maps to 2 samples; the column's vertical fill scales with the value — thick (3 rows of dots) when full, a thin line at the bottom when low. graphs only redraw when a vital actually updates.

multi-row braille: 3 character rows × 4 dot rows per char = 12 dot rows of vertical resolution. for a value v in 0..1 the function lights dots whose global dot row ≥ (1 − v) × 12, so a column fills from the bottom up. full = ⣿⣿⣿ (thick), low = ⣀ at the bottom (thin).
blend layering: the three series are absolutely positioned at the same origin inside .graph with mix-blend-mode: lighten. lit dots add to the displayed color (red + blue = magenta); empty cells contribute nothing under lighten so the dark panel background shows through. no canvas, no svg — just three text layers.
font note: Berkeley Mono Nerd Font's bundled TTF registers the U+2800 braille range with empty (zero-contour) glyphs. The graph font-family stack puts JetBrainsMono Bundled first (zero braille coverage in its cmap, so the browser falls through to Menlo / Consolas which carry real braille glyphs).
