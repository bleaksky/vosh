how tokens work · pass-through · escaping

pass-through: any field your server pushes via Char.Vitals or Char.Worth can be used as %fieldname. Try a token; if the field exists it renders, otherwise it shows in red.

explicit braces: use %{name} when the token is immediately followed by letters or digits that would otherwise be consumed by the greedy match. e.g. %{cp}cp renders the cp field then literal "cp". %% is a literal "%".
