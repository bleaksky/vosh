# Vosh architecture

Later refactor phases add the module map, the lock order, the threads, the command and event catalog and the two traces, one for a line you type and one for a line the game sends.

This file describes the tree as it stands today. Part 2 of `docs/refactor-plan.md` holds the target, and each phase updates the section here that it changes.

## Crates

Vosh is one Cargo workspace. The Tauri app in `src-tauri` uses nine library crates in `crates`. No crate knows about Tauri or the app, so each one builds and tests on its own. A `testkit` feature holds the items only tests call and keeps them out of the release build. The app's dev dependencies turn on the test kits of vosh-prompt, vosh-alias, vosh-trigger and vosh-log, and the vosh-trigger tests turn on the one in vosh-ansi.

## Twins

Two renderers draw the same terminal, xterm on the page and the native grid in Rust. So these jobs exist twice on purpose, and the refactor does not merge them. A change to one side lands on the other side in the same commit, and the Held by column names what keeps the two in step. The last column gives the path Part 2 of the plan sets for each side, and the phase that moves it.

### Pairs kept by hand

Each of these is a value both sides need, and a test fails when the two drift. Where a Rust test reads a page file by its path, R16 moves the page file and that path in the same commit.

- The known worlds. `KNOWN_WORLDS` in `src-tauri/src/profile_set.rs` and in `src/lib/useConnection.ts`. A test in profile_set.rs reads the page's list.
- The presets off marker. `PRESETS_OFF` in `src-tauri/src/loadout_store.rs` and `PRESETS_OFF_MARKER` in `src/lib/automationRecords.ts`. A test in loadout_store.rs reads the page's line.
- The preset library. It lives only in `src/lib/presets.ts`, and tests in `src-tauri/src/loadout_store.rs`, `src-tauri/src/preset_rollout.rs` and `src-tauri/src/commands.rs` read it. `fixtures/room-colors/preset.json` carries the Room, time and weather colors preset to the trigger, session and config tests, and `src/lib/presets.test.ts` holds it equal to the page's copy.
- The UI config defaults. `UiConfig` and its serde defaults in `src-tauri/src/profile_config.rs`, and `normalizeUiConfig` in `src/lib/session.ts`. A test in commands.rs and `src/lib/session.test.ts` both read `fixtures/ui-config/defaults.json`. R19 retires most of the page copy.
- The echo caret, added after the plan. `ECHO_CARET` in `src-tauri/src/input.rs` and in `src/lib/maskedInput.ts`. A test in input.rs reads the page's line.
